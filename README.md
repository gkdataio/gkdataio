## Tools and datasets

- [Security Research Library](https://github.com/gkdataio/security-research-library) supplies the case and program data for vulns.co, with JSON exports, original diagrams, and links to the underlying reports.
- [GatePeek](https://github.com/gkdataio/GatePeek) brings DNS and HTTP results into one subdomain report and keeps links to matching GitHub sources.
- [applyzer](https://github.com/gkdataio/applyzer) identifies a site's frameworks and CMS, including version numbers when available. It can export the inventory as JSON or CSV.
- [Web Directory Inspector](https://github.com/gkdataio/Web-Directory-Inspector) compares HTTP status codes and response sizes across a list of paths.

## Experiments

- [Cryptic Image Messenger](https://github.com/gkdataio/Cryptic-Image-Messenger) turns text into grayscale pixels and back. This [encoded project list](assets/portfolio/project-list.png) sets the height and shade of the blue tiles in my header. Decode it with seed `763`.
- [Python pentesting for beginners](https://github.com/gkdataio/pythonpentestingbeginners) teaches networking and web security through interactive Python exercises.
